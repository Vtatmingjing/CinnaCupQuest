# 竞技场仪式塔阵更新

这次继续把战斗场景往参考图里的海克斯竞技场方向打磨，新增一层低成本但高识别度的场地道具。

## 新增场景层

- `scripts/survivor_3d_view.gd`
  - 新增 `ArenaRitualTowerSet` 根节点。
  - 四角新增大型海克斯/虚空仪式塔。
  - 四边新增副塔，用来强化场地边界和方向感。
  - 新增 6 条低高度能量桥，把塔阵连成一个完整竞技场结构。
  - 塔顶使用已有 `hextech_void_vfx_decal_atlas_v1.png` 裁切符文，和场内弹体/拾取的视觉语言统一。
  - 塔顶符文、脉冲环和水晶只有轻微旋转/呼吸，不引入镜头倾斜、抖动或强运动。

## 视觉目标

- 让场景不再只是“地板 + 边框”，而是更像一个被海克斯装置和虚空仪式侵蚀的战斗棋盘。
- 强化四角、四边和中心的层次，接近参考图里“主战场被装置包围”的观感。
- 保持低网格成本，避免在怪物和弹体很多时压垮性能预算。
