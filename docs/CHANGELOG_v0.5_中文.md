# CHANGELOG v0.5：路线地图、第二关区域与角色选择版

## 新增系统

### 1. 可视化路线地图

新增 `scripts/route_map.gd`，HUD 右侧现在会显示：

- 当前房间进度
- 总房间数
- Boss 节点
- 当前区域名
- 三个下一路线选项
- 已锁定路线

这让路线选择不再只是文字菜单，而是更像肉鸽游戏里的“本局小地图”。

### 2. 角色选择

新增 `scripts/character_data.gd`，主菜单可按 `1 / 2 / 3` 选择角色。

当前角色：

- 小调酒师：平衡型，开局带蜂蜜滴。
- 冰块骑士：防御型，生命和护盾更多，速度略慢，开局带清脆冰块。
- 薄荷忍者：机动型，速度更快，自带二段跳，生命较低，开局带薄荷叶。

### 3. 第二关区域：酒瓶货架

新增 `scripts/region_data.gd`。当局数进入中后段，会从「吧台起点」切换到「酒瓶货架」。

酒瓶货架包含：

- 新背景色调
- 更暗的酒瓶货架背景
- 更多垂直平台
- 玻璃平台风格
- 更高权重的瓶塞骑士
- 新随机事件「瓶子升降梯」

### 4. 区域背景切换

`background.gd` 改为根据区域绘制不同程序化背景：

- 吧台起点
- 酒瓶货架
- 香气祭坛

### 5. 程序化玻璃平台

`platform_visual.gd` 新增 `glass` 风格，用于酒瓶货架和香气祭坛区域。

## 调整内容

- 单局总房间从 8 间扩展到 12 间。
- `_spawn_enemies()` 改为从当前区域的敌人池中抽取敌人。
- 主菜单文案升级为 v0.5，并显示角色列表。
- `README_中文.md` 更新为 v0.5。
- 存档版本号更新为 5。
