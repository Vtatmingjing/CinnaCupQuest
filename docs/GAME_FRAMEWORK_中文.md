# 《Cinna Cup Quest：杯中冒险》游戏框架

## 1. 核心定位

类型：2D 横版动作肉鸽

体验关键词：轻动作、强构筑、幽默幻想、吧台微缩世界、16 位像素风。

一句话：玩家扮演迷你调酒师，在巨大的吧台世界中穿越随机房间，收集配料，组合神奇饮品能力，点亮香气信标并战胜失控的香气之王。

## 2. 核心循环

1. 进入随机路线。
2. 选择或进入下一个房间。
3. 完成战斗、宝箱、休息、事件或 Boss 挑战。
4. 获得配料、杯具、金币或技能。
5. 形成临时构筑。
6. 进入下一房间。
7. 死亡后重新开始，但保留图鉴、解锁和经验。

## 3. 当前 MVP

当前原型先实现：

- 一名玩家角色。
- 六个房间组成的一轮冒险。
- 基础敌人和 Boss。
- 六种道具。
- 胜利与死亡结算。

这不是最终商业版本，而是可玩验证版：验证主题、手感、道具正反馈和肉鸽循环。

## 4. 房间类型

| 类型 | 作用 |
| --- | --- |
| fight | 普通战斗房，清怪后掉落道具 |
| elite | 精英战斗房，更高风险和奖励 |
| treasure | 宝箱房，直接获得配料 |
| rest | 休息房，回血并获得蜂蜜 |
| boss | Boss 房，通关目标 |

## 6. 后续配方系统

后续可以加入三件套联动：

| 配方 | 需要 | 效果 |
| --- | --- | --- |
| 冰薄荷风暴 | 冰块 + 薄荷 + 气泡水 | 冲刺留下冰雾 |
| 肉桂火焰杯 | 肉桂 + 青柠 + 打火机 | 攻击释放火星 |
| 蜂蜜护盾 | 蜂蜜 + 冰块 + 玻璃杯 | 受伤后生成临时护盾 |
| 柠檬暴击流 | 青柠 + 高脚杯 + 肉桂 | 暴击刷新攻击冷却 |

## 7. 美术方向

来自参考图的视觉母题：

- 金色饮品：奖励、能量、通关光效。
- 薄荷绿：速度、生命、弹跳平台。
- 冰蓝：护盾、冰块平台。
- 肉桂棕：桥、武器、关卡机关。
- 红黑打火机：火焰技能、危险机关。
- 木质吧台：基础地形。
- 酒瓶背景：大型场景轮廓。

目标风格：16 位复古像素，清晰剪影，饱满色块，高识别度。

## 9. v0.2 已实现内容

当前原型已经从“线性房间验证版”升级为“基础肉鸽循环版”：

- 玩家每个房间结束后可以选择下一条路线。
- 路线会生成战斗、精英、宝箱、商店、事件、休息和 Boss。
- 商店使用金币购买道具。
- 事件房提供 3 个选择，产生奖励、代价或趣味结果。
- 配方系统已经接入，收集特定道具会自动激活流派。
- HUD 会显示当前配方、金币、路线选择和房间进度。

这意味着项目已经具备一个肉鸽 Demo 的核心闭环：探索路线、战斗、拿奖励、做选择、形成构筑、挑战 Boss。
