# CHANGELOG v0.3：主流程与局外成长版

## 新增系统

### 主菜单

- 游戏启动后不再直接进入战斗，而是显示标题界面。
- 标题界面展示总局数、胜利数、最高分、香气碎片和已解锁开局道具。
- `Enter` 或 `R` 开始新一局，`C` 打开图鉴。

### 暂停菜单

- 游戏中按 `P` 或 `Esc` 暂停。
- 暂停时玩家和敌人会停止行动。
- 暂停菜单支持继续、重新开始、回主菜单、打开图鉴。

### 结算系统

- 玩家死亡或击败 Boss 后进入结算界面。
- 结算显示：最终分数、获得香气碎片、总碎片、最高分、局数、胜利数、本局道具、本局配方和新解锁。

### 局外成长

- 新增“香气碎片”作为局外货币。
- 每局根据分数、推进深度、是否通关获得碎片。
- 到达阈值后自动解锁新的开局道具。

### 图鉴系统

- 收集道具后记录到已发现道具。
- 触发配方后记录到已发现配方。
- 主菜单、暂停、结算页都可以通过 `C` 查看图鉴。

### 存档系统

- 使用 Godot `ConfigFile` 保存到 `user://cinna_progress.cfg`。
- 保存内容包括局数、胜利数、最高分、总分、香气碎片、开局解锁、发现道具、发现配方。

## 修改系统

- `main.gd` 增加状态机：`menu`、`playing`、`paused`、`summary`、`codex`。
- `player.gd` 增加 `set_controls_enabled()`，让菜单和暂停期间可以关闭玩家输入。
- `hud.gd` 增加通用遮罩层，用于主菜单、暂停、结算和图鉴。
- 输入表新增：`confirm`、`pause`、`codex`、`back`。

## 设计意图

v0.3 不追求更多敌人或更多道具，而是补齐肉鸽 Demo 最重要的“局循环”：

开始一局 → 探索 → 死亡或胜利 → 结算 → 获得局外资源 → 解锁更多开局可能性 → 再来一局。

这个循环成立之后，后续增加内容才不会散成一桌未调匀的配料。
