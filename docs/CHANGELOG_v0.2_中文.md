# v0.2 更新记录：肉鸽系统加强版

## 新增系统

### 1. 路线选择

每个非 Boss 房间完成后，HUD 会出现 3 条路线。玩家按 `1 / 2 / 3` 选择下一间房，然后进入右侧传送门。

路线池包含：

- 战斗房
- 精英房
- 宝箱房
- 商店房
- 事件房
- 休息房
- Boss 房

### 2. 金币与商店

敌人死亡会掉金币。商店房会出现 3 个随机商品，走到商品上即可购买。

道具价格会随着房间深度略微上涨，避免后期金币完全失去意义。

### 3. 事件房

事件房当前有 3 个事件：

- 薄荷精灵邀舞
- 肉桂桥谜题
- 冰块朋友敬酒

每个事件都有 3 个选择，用 `1 / 2 / 3` 触发。

### 4. 配方系统

玩家收集特定道具后，会自动发现配方。配方会写入 HUD，并触发额外效果。

当前有 5 个配方：

- 冰薄荷风暴
- 肉桂火焰杯
- 蜂蜜护盾
- 青柠气泡暴击流
- 酒馆厚杯流

### 5. 新道具

新增 4 个道具：

- 杏仁香露：攻击冷却缩短
- 打火星芯：冲刺冷却缩短
- 厚玻璃杯壁：最大生命提升
- 铜制杯底：护盾提升

## 当前玩法目标

v0.2 的目标不是做完整商业版，而是让原型具备“肉鸽的最小灵魂”：

- 每局路线不同
- 每局获得道具不同
- 可以产生配方联动
- 玩家会为了商店和事件权衡路线
- Boss 前能形成一个小流派
