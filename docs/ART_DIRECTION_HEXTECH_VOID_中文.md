# 海克斯虚空美术整改路线

目标不是一次性做成商业成品，而是持续把当前原型推进到“粉丝能一眼看懂、玩家能清楚游玩、性能可控”的成品方向。

## 核心视觉目标

- 战场：深色六边形石板、金色金属边框、蓝色海克斯能量槽、紫色虚空裂纹。
- 英雄：每个角色靠轮廓和武器识别，不靠文字解释。
- 敌人：虚空小怪分工明确，精英和 Boss 有更强体型、发光核心、警示环。
- 弹幕：敌方弹幕必须明显区别于 XP 和玩家技能，使用红/紫高危险色。
- 掉落物：经验、金币、回血、护盾都要有独立形状和颜色。
- 相机：固定俯视，不摇晃、不倾斜，避免头晕。

## 迭代顺序

1. 程序化 3D 风格统一：先用低成本几何体把整体美术语言搭起来。
2. 角色轮廓升级：每个英雄补专属武器、背饰、光环、底座识别。
3. 敌人族群升级：小虫、喷吐、钻地、眼球、甲壳、裂隙水晶、Boss 分别强化外形。
4. 技能特效升级：每个英雄的主攻击和核心技能有不同弹体、光效和地面提示。
5. 半手绘贴图接入：为地砖、金属、虚空甲壳、水晶生成或绘制贴图。
6. 授权模型/图集接入：如果拿到可用资产，再替换程序化占位模型。

## 性能约束

- 普通怪保持低面数，不给每只怪加独立灯光。
- 静态场景可以更精细，动态弹体和敌人必须轻量。
- 粒子和透明材质控制数量，避免怪多时 GPU 压力过高。
- 读图优先于细节，弹幕和拾取物不能被装饰淹没。

## 当前优先整改

- 角色：补英雄底座、能量核心、武器夸张轮廓。
- 敌人：补虚空尖刺、背甲、发光眼、精英/Boss 冠状结构。
- 场景：继续增加海克斯金属层次和虚空污染区域。
- 特效：把技能从“彩色球”推进到“形状可识别的英雄技能”。

## 夜间长跑记录

- 第一批：接入地面/虚空贴图，增强 Boss 剪影和技能脉冲层次。
- 第二批：把竞技场外框推进到八角海克斯结构，补斜切角、边缘能量节点和低干扰地面能量线。
- 第三批：强化敌方弹幕危险轮廓，给拾取物补低强度光柱和底座，提升战斗读图优先级。
- 第四批：透明/发光网格默认不投影，并限制普通怪实时阴影数量，保护怪多时的渲染性能。
- 第五批：新增虚空甲壳和海克斯金属贴图，并让材质系统按用途自动挂贴图且缓存加载。
- 第六批：强化 8 个英雄的俯视剪影，补武器、背饰、星轨、羽翼、重甲和侦察装备等专属识别件。
- 第七批：强化区域技能演出，提莫蘑菇补毒雾孢子，维克托重力场补三角节点，龙王奇点补星轨裂纹，铁男领域补符文石板和锁链。
- 第八批：给范围脉冲增加颜色家族识别，铁男为锁链/锤击，龙王为星爆，莎弥拉为刀痕，霞为羽痕，赛娜为魂光门。
- 第九批：敌方弹幕按虚空怪种类分型，酸液、眼束、晶体、遁地刺、Cho 咬牙弹、Velkoz 聚焦三角和 Belveth 翼刃各有独立危险轮廓。
- 第十批：补竞技场边缘能量接口、外圈节点和小平台，把战斗场景从单纯地砖推进到更完整的海克斯舞台。
- 第十一批：外部授权模型接入时也自动套用英雄专属底座、光环和软阴影，避免高质量模型放入后和当前场景脱节。
- 第十二批：动态脉冲模型使用独立材质副本，避免多个同色技能脉冲同时存在时透明度互相串扰。
- 第十三批：Boss 和精英怪生成时增加场内入场脉冲，让危险单位出现时有更清楚的战斗反馈。
- 第十四批：升级、海克斯和商店选择卡增加左侧色条与文本留白，提升鼠标 UI 的扫读性和质感。
- 第十五批：为 8 个英雄增加职业剪影层，补远程通道、近战刀痕、法师回路、魂光门、毒圈、星轨和暗域链条等角色专属识别符号。
- 第十六批：敌方弹幕增加地面危险十字和菱形轮廓，大额 XP/金币掉落按数值出现晶体环与金币叠层，减少与普通经验混淆。
- 第十七批：升级、命运、海克斯、商店和选人卡片增加小徽章，恢复推荐、稀有度、价格、缺金币等鼠标 UI 信息层级。
- 第十八批：新增敌方弹幕细节预算，密集弹幕超过阈值后新敌弹自动切轻量危险模型，保留读图同时保护性能。
- 第十九批：Boss 增加轮换招式，Cho 扇形咬击、Velkoz 聚焦激光、Rek'Sai 地脉突刺、Bel'Veth 翼刃大扇面，让不同 Boss 有实际战斗差异。
- 第二十批：升级三选一改为“英雄专属/职业路线/随机升级”的倾向结构，并修正商店推荐星标重复问题。
- 第二十一批：海克斯选择池按英雄职业路线加入推荐倾向，物理、法系、坦克、辅助和攻速角色更容易看到契合自身玩法的海克斯。

- 第二十四批：生成原创海克斯/虚空装饰贴图板，并在竞技场边缘补刷怪/能量门、角落锚点和地面通道，让场景构图更接近完整战斗棋盘。
