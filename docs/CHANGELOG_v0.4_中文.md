# CHANGELOG v0.4：战斗手感与关卡质感版

## 新增

- 敌人攻击前摇系统：所有主要敌人攻击前会显示红色像素预警。
- 敌方投射物系统：新增 `projectile.gd`。
- 危险区域系统：新增 `hazard.gd`，支持糖浆、火焰、冰刺。
- 浮动文字系统：新增 `floating_text.gd`，显示伤害、暴击、得分和拾取反馈。
- 程序化像素平台视觉：新增 `platform_visual.gd`，不同平台有木板、冰块、薄荷、肉桂风格。
- 精英词缀：辣味、霜冻、气泡。
- 玩家手感：土狼时间、跳跃缓冲、短跳、命中停顿、受击击退、落地反馈。
- 镜头反馈：命中、暴击、受伤、合成配方、击败 Boss 时会有不同强度的镜头抖动。
- Boss 攻击：火焰弹幕、糖浆区、火焰区、冰刺区。

## 调整

- 战斗房提示加入“观察红色预警”的教学。
- 精英房会额外生成一个糖浆危险区，提高风险收益感。
- 霜冻精英会降低非暴击伤害，鼓励玩家构筑暴击或高伤害流。
- HUD 版本号更新为 v0.4。
- 存档版本号更新为 4。

## 已知限制

- 目前仍使用程序化绘制占位美术，没有正式导入像素精灵表。
- 目前没有音效文件，战斗反馈主要通过视觉、镜头和文字实现。
- 路线选择仍是文字式 UI，下一版建议制作可视化路线地图。
- 没有用 Godot 实机在当前环境中启动测试，建议导入 Godot 后先跑 `scenes/Main.tscn` 检查脚本报错。
