# CHANGELOG v0.6：道具稀有度、主动技能与音效版

## 新增系统

### 道具稀有度

道具现在分为四档：

- 普通
- 少见
- 稀有
- 传说

`item_data.gd` 新增稀有度、稀有度颜色、中文标签、掉落权重和按房间类型调整权重的奖励函数。

### 角色主动技能

新增技能键：`L` 或 `E`。

三名角色获得专属主动技能：

| 角色 | 技能 | 效果 |
| --- | --- | --- |
| 小调酒师 | 摇壶爆发 | 近距离范围伤害 |
| 冰块骑士 | 冰杯守护 | 获得护盾，短暂无敌，震开近身敌人 |
| 薄荷忍者 | 薄荷闪身 | 向前瞬移并造成落点伤害 |

### 程序化音效

新增 `sound_manager.gd`。当前音效通过代码实时生成，不依赖外部音频素材。

已接入音效：

- 菜单选择
- 开局
- 攻击
- 冲刺
- 主动技能
- 拾取
- 稀有拾取
- 配方发现
- 敌人死亡
- 玩家受伤
- 路线锁定
- 胜利
- 失败

### 技能释放视觉

新增 `skill_burst.gd`，主动技能释放时显示不同颜色的像素扩散环。

## 新增道具

| 道具 | 稀有度 | 效果 |
| --- | --- | --- |
| 香草云 | 少见 | 回复生命并获得护盾 |
| 滋补汤力水 | 稀有 | 主动技能冷却缩短 |
| 八角星尘 | 传说 | 主动技能威力提升 |
| 金糖晶 | 传说 | 立即获得金币和分数 |

## 新增配方

| 配方 | 需要道具 | 效果 |
| --- | --- | --- |
| 星尘摇壶 | 八角星尘 + 滋补汤力水 + 气泡水 | 主动技能冷却进一步缩短，技能威力提升 |
| 金糖敬酒 | 金糖晶 + 蜂蜜滴 + 厚玻璃杯壁 | 金币收益提升，最大生命提升 |

## HUD 更新

- HUD 显示主动技能状态。
- 增加主动技能冷却条。
- 图鉴显示道具稀有度。
- 结算页显示带稀有度的本局道具。

## 局外解锁更新

新增两个开局道具解锁：

- 42 香气碎片：香草云软垫
- 54 香气碎片：汤力水技能票
