# CHANGELOG v0.8：试玩完成度增强版

## 新增

- 新增主菜单动画 `scripts/menu_animation.gd`：绘制动态玻璃杯、香气火苗、气泡轨道和像素礼花。
- 新增程序化像素 Tileset `scripts/pixel_tileset.gd`：统一木板、冰块、薄荷、肉桂和玻璃平台的绘制逻辑。
- 新增角色“柠檬枪手”：主菜单按 `4` 选择。
- 新增主动技能“青柠连珠”：向前方扇形范围造成酸甜弹幕伤害，适合远程风筝。
- 新增道具“柠檬皮弹匣”：主动技能威力 +1。
- 新增配方“柑橘连珠”：青柠星片 + 柠檬皮弹匣 + 杏仁香露。
- 新增通关短演出：击败最终 Boss 后显示“香气信标点亮”演出页，几秒后进入结算。
- 新增新手提示卡：基础操作、路线选择、事件房、商店和 Boss 战首次出现时给出简短提示。
- 新增局外解锁：66 香气碎片解锁“柠檬皮弹匣许可证”。

## 调整

- 主菜单说明更新到 v0.8，并显示四名角色。
- HUD 底部帮助文本更新，区分路线 / 事件选择和角色选择。
- 平台视觉由 `platform_visual.gd` 转为调用 Tileset 绘制，便于后续替换为真正贴图素材。
- 最终 Boss 击败后不再立即结算，而是先进入 `victory_scene` 状态。

## 需要重点测试

1. Godot 导入后运行 `scenes/Main.tscn` 是否正常进入主菜单。
2. 主菜单按 `1 / 2 / 3 / 4` 是否能切换角色。
3. 柠檬枪手普通攻击距离是否明显长于其他角色。
4. 柠檬枪手 `L / E` 主动技能是否能伤害前方敌人。
5. 收集青柠星片、柠檬皮弹匣、杏仁香露后是否触发“柑橘连珠”。
6. 清房后的路线选择、事件选择和商店购买是否仍正常。
7. 击败最终 Boss 后是否进入通关短演出，再进入结算页。
8. 存档中已有旧版本数据时，设置和局外解锁是否仍能读取。
