# 英雄专属武器剪影层更新

本轮目标是提升粉丝向辨识度：不再只靠颜色和普通特效区分英雄，而是给每个英雄增加一层独立的职业/武器/被动机制剪影。

## 新增内容

- 新增 `ChampionKitSilhouette` 根节点，所有英雄都会生成。
- 新增 `ChampionKitRolePlate`：显示职业定位牌，例如射手、决斗者、控制法师、重装战士、陷阱型、星界法师。
- 新增 `ChampionKitWeaponIcon`：用轻量 3D 几何表现专属武器轮廓。
- 新增 `ChampionKitPassiveMotif`：用环绕符号表现被动或核心机制。

## 英雄识别方向

- 金克丝：鱼骨头火箭、砰砰枪管、蓝粉弹链。
- 赛娜：遗物大枪、灵魂炮口、赦除魂环。
- 莎弥拉：双刀双枪、近战连招斩痕、风格评分感。
- 维克托：法杖、海克斯核心、进化电路。
- 霞：羽毛扇形、倒钩回收符号。
- 莫德凯撒：夜陨巨锤、死亡领域、锁链环。
- 提莫：吹箭、蘑菇、陷阱孢子。
- 奥瑞利安·索尔：星核、彗星、星轨。

## 性能约束

该层只使用少量 Godot 原生网格，不引入高面数模型，不增加运行时贴图加载压力。后续如果接入授权 GLB/贴图，也可以保留该层作为顶视角识别和技能提示层。

## 测试覆盖

`tests/survivor_champion_visual_matrix.gd` 已新增检查：

- 每个英雄必须存在 `ChampionKitSilhouette`。
- 必须包含职业牌、武器剪影、被动符号三块内容。
- 武器剪影必须带有对应英雄的 `weapon_signature` 元数据。
- 剪影层网格数量不能过低，避免空壳节点通过测试。
