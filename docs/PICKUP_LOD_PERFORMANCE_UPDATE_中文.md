# 拾取物 LOD 性能更新

这次没有继续堆新特效，而是给高压战斗做了一轮视觉减重。

## 改动内容

- `scripts/survivor_3d_view.gd`
  - 新增 `PICKUP_DETAIL_LIMIT`。
  - 当场上拾取物超过阈值时，普通 XP 拾取物会切换为 `LitePickupModel`。
  - 轻量 XP 仍保留颜色、大小和地面光环，用来区分经验价值。
  - 金币、治疗、护盾和高价值奖励仍保留完整高级视觉，例如图标盘、光柱、奖励信标和悬浮徽记。

## 为什么这样做

- 当前场面已经有 3D 竞技场、英雄徽记、敌人标识、弹体读条和高价值掉落提示。
- 继续给每个普通 XP 堆特效会挤占 CPU/GPU 预算，也会让画面更乱。
- 普通 XP 在密集场中只需要清楚可见，不需要每颗都拥有完整装饰层。

## 验证

- `tests/survivor_visual_budget_smoke.gd`
  - 预算从 `8400 mesh / 11000 node` 收紧为 `7200 mesh / 9000 node`。
  - 新增断言：高压场景必须生成 `LitePickupCore`，证明密集 XP LOD 已启用。
- 高压测试结果约为 `6000 mesh / 7600 node`，为后续继续打磨美术留出空间。
