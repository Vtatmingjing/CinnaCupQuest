# 商店装备图标货架更新

这次把商店从文字型商品卡推进到更接近参考图的装备货架表现。

## 新增资产

- 新增 `art/textures/hextech_shop_item_icon_atlas_v1.png`。
- 这是一张 4x4 原创装备图标图集，风格为暗底、金属、海克斯蓝光和虚空紫光。
- 图标不直接复制官方装备图标，但保留了玩家能快速理解的装备读感：大剑、电刃、吸血刀、飓风、法帽、护盾、沙漏、铠甲、宝箱等。

## HUD 改动

- `scripts/survivor_hud.gd`
  - 商店卡片现在使用 46px 大装备图标。
  - 新增价格牌，金币不足时使用红色低亮状态。
  - 新增路线文字，例如物理、暴击、射手、法系、坦克、近战、召唤、支援。
  - 新增 3 段推荐强度条，当前英雄越适配越亮。
  - 普通升级、海克斯选择和选人卡仍走原有卡片逻辑，不被商店专属视觉影响。

## 验证

- `tests/survivor_hud_visual_matrix.gd`
  - 检查英雄头像仍正常。
  - 检查升级/海克斯图标仍正常。
  - 新增商店装备图集尺寸、装备大图标、价格牌、路线标签、推荐强度条断言。
