# Cinna Cup Quest：杯中冒险

这是一个 Godot 4 的 2D 俯视角自动攻击弹幕肉鸽原型项目，玩法方向已调整为类似《吸血鬼幸存者》的生存构筑循环。主题仍来自上传图片：玻璃杯、金色饮品、冰块、薄荷、肉桂、木质吧台、红黑打火机与酒瓶背景，被转化为一个幽默的微缩吧台幻想世界。

当前版本保留“迷你调酒师英雄”和“杯中冒险”的世界观，但游戏类型从横版房间闯关改为：在巨型吧台竞技场中移动走位、自动攻击、收集配料经验、三选一升级、对抗持续涌来的气泡怪/冰块/青柠/软木塞敌人，并在后期挑战香气信标守护者。

## 当前版本：v0.8 试玩完成度增强版

v0.8 的目标是让原型更像一个可以给别人试玩的 Demo：主菜单不再只是文字页，而是有杯影、气泡和像素礼花的动态背景；平台视觉改为程序化像素 Tileset；新增第四名角色“柠檬枪手”；通关后会进入短演出再结算；同时加入更清晰的新手提示，帮助玩家理解移动、攻击、路线、事件、商店和 Boss 读招。

### 本版新增

- 主菜单动画：标题页有巨型玻璃杯、香气火苗、气泡轨道和像素礼花。
- 程序化像素 Tileset：木板、冰块、薄荷、肉桂、玻璃平台现在使用统一的 Tile 风格绘制逻辑。
- 新角色：柠檬枪手，远程暴击型角色，拥有更长攻击距离和“青柠连珠”主动技能。
- 新道具：柠檬皮弹匣，提升主动技能威力。
- 新配方：柑橘连珠，由青柠星片、柠檬皮弹匣、杏仁香露组成。
- 通关短演出：击败最终 Boss 后先播放“香气信标点亮”结局页，再进入结算。
- 新手提示卡：首次进入关键系统时显示 TIP，包括基础操作、路线选择、事件、商店和 Boss。
- 局外解锁更新：新增 66 香气碎片解锁“柠檬皮弹匣许可证”。

## 操作方式

- W / A / S / D 或方向键：俯视角移动
- 攻击为自动锁敌发射，不需要手动按攻击键
- 1 / 2 / 3：升级时选择配料强化
- 1 / 2 / 3 / 4：主菜单选择角色
- Enter：开始 / 继续 / 结算后再来一局
- P / Esc：暂停 / 返回
- R：快速重开一局

## 如何运行

1. 安装 Godot 4.x。
2. 打开 Godot。
3. 选择“导入 / Import”。
4. 选中本项目文件夹中的 `project.godot`。
5. 打开项目后运行 `scenes/Main.tscn`。

## 难度设置

| 难度 | 效果 |
| --- | --- |
| Cozy / 轻松 | 玩家开局 +1 最大生命和 +1 护盾，敌人血量、伤害、速度略低。 |
| Normal / 标准 | 默认体验。 |
| Spicy / 辛辣 | 敌人更硬更快，后期和 Boss 伤害更高，但奖励分数略高。 |

## 文件说明

- `scripts/main.gd`：主流程状态机、菜单、设置、角色选择、暂停、结算、通关演出、区域切换、房间流程、路线选择、商店、事件、敌人和奖励生成。
- `scripts/player.gd`：玩家移动、攻击、主动技能、受伤、金币、道具效果、配方触发、角色应用和手感优化。
- `scripts/character_data.gd`：可选角色数据、主动技能数据。
- `scripts/menu_animation.gd`：主菜单杯影、气泡、像素礼花动画。
- `scripts/pixel_tileset.gd`：程序化像素 Tileset 调色板与平台绘制逻辑。
- `scripts/region_data.gd`：区域名、平台风格、敌人池和背景切换数据。
- `scripts/route_map.gd`：HUD 上的小型路线地图。
- `scripts/route_overlay.gd`：清房后的全屏路线节点选择界面。
- `scripts/enemy.gd`：敌人 AI、区域 Boss、攻击前摇、精英词缀、投射物与危险区请求。
- `scripts/projectile.gd`：敌方投射物。
- `scripts/hazard.gd`：预警后生效的地面危险区。
- `scripts/floating_text.gd`：伤害数字、暴击和拾取反馈。
- `scripts/platform_visual.gd`：调用程序化 Tileset 绘制像素平台。
- `scripts/meta_progress.gd`：局外进度、设置、香气碎片、解锁、图鉴和存档。
- `scripts/item_data.gd`：道具数据、稀有度、价格与掉落权重。
- `scripts/recipe_data.gd`：配方数据。
- `scripts/item_pickup.gd`：掉落物拾取、稀有度视觉和商店购买。
- `scripts/sound_manager.gd`：程序化复古音效管理器。
- `scripts/skill_burst.gd`：角色主动技能释放视觉。
- `scripts/decor.gd`：商店老板、事件 NPC、宝箱、香气信标等装饰。
- `scripts/door.gd`：通关门。
- `scripts/hud.gd`：HUD、技能冷却条、路线地图、路线选择界面、主菜单、暂停、设置、结算、通关演出和图鉴界面。
- `scripts/background.gd`：按区域切换的程序化背景。
- `art/reference_drink.jpg`：原始参考图。
